# Примеры приложений на C
В данном репозитории представлены простых приложений на C для использования в качестве учебных примеров. Для каждого примера имеется скомпилированный exe файл для запуска приложений. 

**Архив имеет следующее содержимое:**
- simple_multiplication - Проект содержит программу на C производящую умножение чисел через сложение 
- even_counter - Проект содержит программу на C получающая 10 чисел и считающая чётные и нечётные из них
- replace_char - Проект содержит программу на C принимающая строку и заменяющая в ней все символы "?" на "!"
- triangle_determinant - Проект содержит программу на C получающая длины сторон треугольника и после чего проверяющая существует ли он и какой у него тип
- number_degree - Проект содержит программу на C возводящую первое число в степень второго числа через умножение в цикле
- binary_convert - Проект содержит программу на C конвертирующее вводное двоичное число в десятичный формат
- calculator - Проект содержит программу на C являющаяся простым калькулятор двух чисел с операциями +, -, *, /, ^ (степень) и % (остаток)
- define_ipmask - Проект содержит программу на C считывающее указанный IP-адрес и определяющее класс сети (A/B/C/D/E) по первому октету
- build_ipmask - Проект содержит программу на C выполняющее построение маску подсети по введённой CIDR (/24)
- encryption - Проект содержит программу на C реализующая шифр, в соответствии с которым шифруется входящая строка, состоящий из трёх шагов: смена мест соседних символов, разворот строки, шифр Виженера
- reverse_string - Проект содержит программу на C производящее переворот входной строки
- simple_editor - Проект содержит программу на C являющаяся простым тектсовым редактором файлов. Для корректной работы требуется запускать программу через cmd консоль с передачей аргументов в следующем формате "editor.exe <название файла> <режим работы: W - запись строки, S - чтение строки> <для W - текст новой строки, для S - номер строки для чтения и вывода>"
- game_wordmake - Проект содержит программу на C являющаяся простенькой игрой, которая считает «очки» для введённых слов двух игроков по таблице стоимости букв и определяет победителя
